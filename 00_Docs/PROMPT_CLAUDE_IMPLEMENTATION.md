# Claude Implementation Prompt

> Diesen Prompt in Claude Chat einfügen, um die Live-Session zu starten.
> Immer mit M0 beginnen. Prompt wird nach jedem Milestone-Abschluss aktualisiert.

---

Siehe Hauptprompt in der Claude-Projekt-Instruction (SiCKaRiM & einfachfyn FL Studio Preset Lab).

**Schnell-Start:**

```
Starte mit M0.
Stelle mir genau eine Frage zur Stilentscheidung.
Erstelle danach 00_PROJECT_DIRECTION.md als Markdown.
Fahre erst fort, wenn ich PASS schreibe.
Bei jedem Meilenstein: genau ein Test, MIDI/Audio/Clock getrennt dokumentieren,
bei unbekannten Ports/Kanälen/Firmware einen Screenshot oder Foto anfordern.
```
