# Routing Log

> Jeden PASS-Test hier eintragen.

## Format

```
### M[X] – [Name]
Datum: YYYY-MM-DD
Status: PASS / FAIL
Signalweg: [Device] → [Kabel] → [Interface Input] → [FL Mixer Insert] → [Bus] → [PreMaster] → [Master]
Clock: [Master] / [Slave] / [unabhängig]
MIDI Port: [Port]
MIDI Channel: [CH]
Audio Device: [Name]
Sample Rate: [Hz]
Buffer: [ms]
Screenshot: [Dateiname oder Link]
Notiz: [Freitext]
```
