# Erstes 165-BPM-Tekk-Pattern — Workflow

Kategorie B (praktische Workflow-Empfehlung). Die konkreten Bedienschritte
für jeden Punkt stehen in `electribe-basics.md` und sind dort einzeln als
Kategorie C markiert, bis eine Handbuch-Auswertung stattgefunden hat.

Style-Referenz: Hard Tekk / Rave Tekk / Dark-/Psy-Tekk, Standardtempo 165 BPM.

## Ablauf

1. **Leeres Pattern wählen, Tempo auf 165 BPM setzen.**
   Bedienschritt: siehe `electribe-basics.md` → Sequencer / Pattern-Grundlagen
   (Kategorie C).

2. **Kick-Part programmieren.**
   Ziel: einfacher, durchgehender Grundpuls als Fundament für Hard Tekk.
   Bedienschritt: siehe `electribe-basics.md` → Part-Auswahl (Kategorie C).

3. **Bass-Part programmieren.**
   Ziel: Bass-Linie, die rhythmisch zur Kick passt (z. B. Rolling- oder
   Sub-Charakter — Kategorie B, kein fester Universal-Wert).
   Bedienschritt: siehe `electribe-basics.md` → Part-Auswahl, Level, Filter
   (Kategorie C).

4. **Percussion-Layer ergänzen.**
   Ziel: zusätzlicher Groove über Hats/Percs, ohne die Kick zuzudecken.

5. **Rave-/Noise-Akzent hinzufügen.**
   Ziel: ein Akzent-Sound (z. B. an einer Break- oder Fill-Stelle) als
   stilprägendes Element.

6. **Variation erzeugen.**
   ⚠️ Kategorie C: Der genaue Mechanismus (zweiter Part-Slot, Mute-Automation,
   o. Ä.) ist am Gerät noch zu prüfen, bevor hier eine feste Empfehlung
   gegeben werden kann.

7. **Speichern (Write).**
   Vor jedem Verlassen des Patterns: Write-Reminder gemäß `SKILL.md`
   Abschnitt 6. Bedienschritt: siehe `electribe-basics.md` → Speichern
   (Kategorie C).

## Checklisten

**Vor Patternwechsel:**
- [ ] Write durchgeführt?
- [ ] Notiz im Pattern-Blatt (Tempo, Pattern-Slot, Datum)?

**Vor dem Ausschalten:**
- [ ] Write abgeschlossen (kein laufender Speichervorgang)?
- [ ] Pattern-Nummer notiert?

**Session-Abschluss:**
- [ ] Pattern-Nummer(n) und Datum im Pattern-Blatt eingetragen?
- [ ] Optional: Foto vom Display für spätere Handbuch-Auswertung gemacht?
